Do a mask hole and a box laid on it meet at a fractional edge?

Each surface is a hole cut in a scrim with a halo laid flush on it in the scrim's own colour, so where the two meet the edge cannot be seen. A bright line along an edge is a gap, where neither paints; a darker line is an overlap, where both do.

What each column does

Leko Scroll cuts its hole as a data: SVG image in a mask layer, placed with mask-position at the image's own size, and lays the halo on the same rectangle as an ordinary box. Each surface above does the same by hand.

Each case is drawn three ways. raw writes the rectangle as it came, the way the scrim does today — two decimals in the mask, every digit in the box. whole CSS px moves each edge to the nearest whole CSS pixel first. device px moves each edge to the nearest device pixel instead, 1 / devicePixelRatio of a CSS pixel.

Judge by eye when the page is opened by hand, Safari included: a page cannot read its own pixels. run.mjs hands the page a screenshot of itself, and the page reads that and draws the table below.
