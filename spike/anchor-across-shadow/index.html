Does CSS anchor positioning cross a shadow boundary?

A product tour puts a message beside the element it is pointing at. The cheap way to keep the two together through every scroll is CSS anchor positioning: write an anchor-name onto the target, and give the message position-anchor with the same name. No JavaScript runs again afterwards.

That works while both elements are in the same tree. The question here is what happens when the target is inside a shadow root and the message is not — which is every tour pointing at a web component, and there are a lot of those.
