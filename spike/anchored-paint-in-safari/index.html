Does an anchor-positioned box still get painted?

A product tour keeps its message beside the element it is pointing at with CSS anchor positioning, and puts the message in the top layer so the page's own stacking contexts cannot outbid it. Both halves are ordinary. The question here is whether a browser that lays such a box out correctly also paints it.

Eight boxes, all anchored to a zero-area marker, all with a white background and a red border. The rows differ in where the marker lives; the columns differ in how the box is drawn. Every readout below reports the rect the browser measured, so a box that is missing from the screen while its readout says anchored is one the browser laid out and did not paint.

Read this page with your eyes. No script can ask whether something was painted — getBoundingClientRect, checkVisibility and elementFromPoint all answer for a box that never reached the screen. Count the red-bordered boxes you can see and put the number in the field at the bottom.
