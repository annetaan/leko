What says a same-document URL changed?

This page runs eight actions once, on load, in order: pushState, pushState again, replaceState, setting location.hash, a click on an in-page <a href>, then history.back() twice and history.forward() once to walk back across the entries the earlier actions made. It draws its measurement below as it runs; node run.mjs reads the same window.spikeNavigation.measure() this page draws from, in more than one engine.

What fires, and when

One row per action. fired is every event that ran, each marked sync if it ran while the triggering call was still on the stack or later if it ran as a task after that call returned. location matches is whether every fired event's handler read location as the URL the action produced — the thing a step waiting for a URL needs to be true regardless of timing.
