Which ancestors take position: fixed away from the viewport?

A fixed element is positioned against the viewport unless an ancestor establishes a containing block for it, and then it behaves as if it were absolutely positioned inside that ancestor and scrolls with the page. The specification lists the properties that do this. Whether every engine agrees, and whether anything on the element reports it, is what this page measures.

Every chip along the top of the window is a position: fixed element inside a wrapper that sets one property. Scroll the page: the chips that stay are still fixed, the ones that leave have been carried off.
